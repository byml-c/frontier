我希望搭建一个 Agent 驱动的论文库，职责包括每日从各个源读取论文，过滤论文，对论文进行简要分析，呈现成日报的形式。长期维护研究方向进展，将论文划分到研究方向，并长期维护更新进展。具体来说，我希望构建以下几个功能模块：

# 论文收集系统和论文库

从会议、RSS 源、Arxiv、公众号文章等数据源收集论文，整理入库。

# 基于图结构的研究方向进展维护系统

每一个研究方向是一个节点，每个节点可以关联多篇论文，目的是通过节点的演化和发展持续追踪和关注一个领域、一个热点科研方向的长期进展。节点间应该是有向图关系，代表演化方向。每个节点至少应该包含研究内容，解决的问题，仍然存在的问题。

进入图结构的论文应当是解决具体问题、值得精读、对领域发展有切实推动作用或提出了新的思考的优质论文。

# 论文核心提取和阅读系统

使用知识链接模式和问题分解方式，对单篇论文进行精读，对一个领域/一个研究方向节点/跨研究方向节点的论文进行增量阅读。我关注的主要是具身智能领域的论文，包括 VLA、WAM、移动操作、触觉、仿真、评测、遥操、3DV 的具身应用等领域。我希望论文的精读可以帮我建立知识链接，学习到其解决了什么问题、定义了什么方法、对方法的思考和设计、实验效果、不足和仍待解决的问题。
